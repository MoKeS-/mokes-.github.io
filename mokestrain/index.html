Installation

Trois étapes, deux minutes

  1. Télécharge l'APKDepuis le téléphone, touche « Télécharger l'app ». Le fichier arrive dans Téléchargements.
  2. Ouvre le fichierTouche la notification de téléchargement, ou retrouve le fichier dans l'app Fichiers.
  3. Autorise et installeSi Android le demande, autorise l'installation depuis ton navigateur, puis touche « Installer ».

Version de test. Les mises à jour du pilote s'installeront par-dessus. La version définitive demandera de désinstaller celle-ci d'abord, et tes réglages seront à refaire.
